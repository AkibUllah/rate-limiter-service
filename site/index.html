Rate Limiter Service

Distributed rate limiting as a library, an ASGI middleware and a standalone service: token bucket, fixed window, sliding log, sliding window counter and GCRA over in-memory or Redis backends.

Source on GitHub Open in Codespaces Deploy to Render

This page is a static API reference built from the service's exported OpenAPI document on every push to main; there is no backend behind it, so requests cannot be sent from here. Open the Codespace to run the real service with demo data, or deploy your own copy to Render. The Codespace runs two Redis-backed replicas and seeds an otp policy (5 per 5 minutes, sliding log) to check keys against.
